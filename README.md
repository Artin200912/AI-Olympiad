# AI Olympiad Class Materials

Course materials organized by subject, week, and exam.

## Contents

- `subjects/calculus/` — calculus exercises.
- `subjects/probability/` — probability and combinatorics exercises.
- `subjects/linear-algebra/` — linear algebra class materials.
- `subjects/python-coding/` — programming notebooks and their supporting data, including machine-learning coding sessions. Eight queens is in week 2; graph search is in week 5.
- `subjects/machine-learning/` — machine-learning notes and readings.
- `subjects/exercise-solving/` — teacher-led exercise-solving materials, including the 11 Mehr class notes, 15 Shahrivar whiteboard, and annotated notes from 23 August.
- `exams/` — numbered exams, summer theory exams, and the marathon, with questions and solutions where available.
- `books/` — reference books and solutions.

Notebook variants are retained where they differ. A filename alone does not guarantee that every exercise is complete. The week 11 linear-regression notebook refers to `data/california_housing.csv` and `data/polynomial_dataset.csv`, which are not included; it needs those files to run fully.

The class notes dated 11 Mehr and 13 Mehr are filed under exercise solving and machine learning, respectively. Their year has not been specified.
